HOW TO PLAY

  • 🎲 Take turns counting up, just like passing the dice in Ludo. Each turn you get ONE number.
  • 🔢 If the number is safe, find it on the big board and tap it.
  • 💣 If it is a BUMMM number, tap the red BUMMM! button instead.
  • ✨ A number is BUMMM if it is a multiple of the magic number or contains it. Level 1 magic number is 3, so 3, 6, 9, 12, 13, 23, 30… are all BUMMM!
  • ❤️ Wrong tap or too slow? You lose a heart. Lose all 3 and you're out. Last one standing wins!
  • 🪜 Every level the magic number grows: 3, 5, 7, 9, 11… forever, and the clock gets faster.
